# SoundCloud Playback Explorer

This project contains a Node.js script using Playwright to explore and scrape SoundCloud "Your Playback" sets from 2025 down to 2017. It also includes a frontend visualization to view the scraped data.

## Prerequisites

- Node.js installed
- `npm` installed

## Installation

1. Install dependencies:
   ```bash
   npm install
   ```
   (This will install `playwright` and `playwright-core`)

2. Install Playwright browsers (if not already installed):
   ```bash
   npx playwright install
   ```

## Usage

### Scraper

To run the scraper:

```bash
node soundcloud_explorer.js
```

This script will:
- Launch a Chromium browser.
- Iterate through years 2025 to 2017.
- Navigate to `https://soundcloud.com/discover/sets/your-playback::0cater:{year}`.
- Scroll down to load all tracks.
- Extract track information (Title, Artist, Artwork URL).
- Download high-resolution artwork to `downloads/{year}/`.
- Save the aggregated data to `playback_data.json`.

**Note:** You might need to handle login or authentication if the sets are private or require a user session. The current script assumes public access or that the browser context handles it (the script runs in a non-persistent context by default, so it might only work for public sets or require modification to inject cookies). The prompt URL pattern `your-playback::0cater` suggests a specific user or generated playlist.

### Visualization

To visualize the scraped data:

1. Ensure `playback_data.json` and the `downloads/` folder are present (generated by the scraper).
2. Start a local HTTP server. For example, using Python:
   ```bash
   python3 -m http.server 8080
   ```
3. Open `http://localhost:8080` in your web browser.

The interface displays a Bento Grid layout of the tracks, separated by year, with dark mode enabled.

## Files

- `soundcloud_explorer.js`: The main Playwright script.
- `index.html`: The HTML file for visualizing the data.
- `package.json`: Project dependencies.
